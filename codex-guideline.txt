# SYSTEM SPECIFICATION: News Archive Asset ID Generation

## 1. Syntax & Schema Overview
An Asset ID is a deterministic, 5-segment delimited string separated by underscores (`_`).

Format:
[SLUG]_[SUBTYPE]_[ASSET_TYPE]_[DATE]_[SEQUENCE]

Delimiter: `_` (ASCII 0x5F)
Allowed Character Set: `[a-z0-9_]` (Strictly lowercase alphanumeric and underscores)
Regex Pattern: `^(?=.{21,28}$)[a-z0-9]{3,10}_[a-z0-9]{0,1}_[a-z0-9]{3}_\d{6}_\d{3}$`

---

## 2. Segment Rules & Constraints

### Segment 1: Topic / Location Slug
- Purpose: Short identifier for news topic or geographic location.
- Type: Alphanumeric String (`a-z`, `0-9`, `_`)
- Length: 3 to 10 characters (Strictly truncated at 10).
- Sanitization:
  - Convert to lowercase.
  - Remove special characters (`#`, `@`, `-`, etc.).
  - Replace spaces with single underscores (`_`).
  - Trim leading/trailing underscores (e.g., `_coxbazar` -> `coxbazar`).

### Segment 2: Sub-Classification Modifier
- Purpose: Optional single-character taxonomy filter (e.g., `s`, `l`, `a`, `m`, `u`).
- Type: Single Alphanumeric Character or Empty String.
- Length: 0 to 1 character.
- Structural Behavior: When empty, retains adjacent delimiters, creating double underscores (`__`) between Segment 1 and Segment 3.

### Segment 3: Asset Type Code
- Purpose: Identifies media material type.
- Type: Fixed 3-character enumeration.
- Allowed Values:
  - `edc` : Edit Card / Packaged Edit
  - `gvw` : General View / B-Roll
  - `nws` : Raw News Feed
  - `gfx` : Still Graphic / Motion Asset
- Length: Exactly 3 characters.

### Segment 4: Asset Ingest Date
- Purpose: Temporal marker.
- Type: Numeric String.
- Date: Date must be recent date not selected data by react date piker.
- Format: `DDMMYY` (Day: 2 digits, Month: 2 digits, Year: 2 digits).
- Length: Exactly 6 digits (`\d{6}`).

### Segment 5: Daily Sequence Counter
- Purpose: Unique identifier counter per asset type per day.
- Type: Zero-padded integer string.
- Range: `001` through `999`.
- Length: Exactly 3 digits (`\d{3}`).

---

## 3. Storage Constraints
- Minimum Total Length: 21 characters (e.g., `bnp__edc_090122_001`)
- Maximum Total Length: 28 characters (e.g., `trade_fair_s_edc_090122_001`)
- SQL Type Recommendation: `VARCHAR(32)` or `CHAR(28)`
